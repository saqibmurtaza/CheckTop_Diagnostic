CHECKTOP LAPTOP DIAGNOSTIC AGENT
================================

HOW TO USE:
1. Double-click 'run-diagnostics.bat'
2. Wait for the diagnostics to complete (about 2-5 minutes)
3. Your report will be saved to:
   %APPDATA%\CheckTop Local Agent\last_report_human.json

REQUIREMENTS:
- Windows 10 or Windows 11
- No installation needed!
- Runs completely offline

WHAT IT CHECKS:
- Battery Health
- CPU Performance & Temperature
- Storage Health (SMART data)
- Display for dead pixels
- USB, HDMI, and Audio ports

TROUBLESHOOTING:
- If you get a security warning, click "More info" then "Run anyway"
- SMART disk checks require Administrator privileges
- All tests are safe and non-destructive

SUPPORT:
Visit: https://checktop-frontend.onrender.com/

📥 FIRST TIME HERE? - HOW TO GET STARTED:

   Your download came as a ZIP file (like a compressed package).
   Don't worry - just follow these simple steps:

   STEP 1️⃣: RIGHT-CLICK the downloaded ZIP file
   STEP 2️⃣: Select "Extract All..." from the menu
   STEP 3️⃣: Click "Extract" in the window that pops up
   STEP 4️⃣: Open the newly created folder

   That's it! You now have all the files ready to use.

🚀 RUNNING THE DIAGNOSTIC:

   1️⃣ Double-click the file named:  run-diagnostics.bat
      (It looks like a small window icon)

   2️⃣ If Windows shows a warning, click:
      "More info" → "Run anyway" (This is normal - the app is safe)

   3️⃣ The diagnostic will run for 2-5 minutes.
      ⏳ Please wait - don't close the window!

   4️⃣ When complete, your report will open automatically.

▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀

📋 WHERE TO FIND YOUR REPORT:

   After the test finishes, your report is saved here:
   📁 %APPDATA%\CheckTop Local Agent\last_report_human.json

   QUICK WAY TO OPEN IT:
   • Press Windows Key + R on your keyboard
   • Type: %APPDATA%\CheckTop Local Agent
   • Press Enter
   • Double-click "last_report_human.json"

   The report will open in your default text editor (like Notepad).
